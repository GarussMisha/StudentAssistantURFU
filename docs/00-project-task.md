## Краткое название

Разработка ИИ-ассистента для студентов на основе RAG-архитектуры и методологии
проектной деятельности

## Описание

Студенты, работая над проектами, часто сталкиваются не с техническими, а с
методологическими трудностями: как планировать задачи, вести документацию,
распределять роли. Этот проект предлагает создать ИИ-ассистента, который станет
для них «карманным» ментором. В отличие от обычных LLM, он будет давать ответы
строго на основе проверенной базы знаний (статьи, книги, ГОСТы по Agile, Scrum,
DevOps и т.д.).

## Этапы работы

1. Сбор и структурирование базы знаний: подборка материалов по управлению
   проектами и инженерным практикам.
2. Выбор и настройка векторной базы данных для хранения знаний.
3. Разработка RAG-пайплайна: интеграция LLM (например, через API) с векторной
   базой данных.
4. Создание простого пользовательского интерфейса (веб-страница или
   телеграм-бот).
5. Тестирование и итеративное улучшение качества ответов ассистента.

## Уровни результата

### Минимальный

Сформированная и векторизованная база знаний по проектной деятельности; скрипт,
демонстрирующий базовую логику RAG (запрос → поиск → ответ).

### Базовый

Рабочий прототип ИИ-ассистента с базовым интерфейсом, отвечающий на прямые
вопросы по базе знаний.

### Оптимальный

Развёрнутый ассистент с удобным веб-интерфейсом, возможностью отслеживания
контекста диалога и сбора обратной связи от пользователей для улучшения системы.

## Цель

Получение студентами практических навыков в разработке современных
LLM-приложений с использованием Retrieval-Augmented Generation (RAG), а также
систематизация знаний в области инженерных практик и управления ИТ-проектами.

## Требуемый результат

Веб-сервис или чат-бот (ИИ-ассистент), который консультирует студентов по
вопросам ведения проектов (например, «Как правильно составить ТЗ?», «Какие
этапы у Scrum?»), основываясь на загруженной базе знаний по лучшим инженерным
практикам.

## Критерии оценки

1. Развёрнут и доступен для тестирования ИИ-ассистент.
2. Качество ответов ассистента оценено как релевантное на наборе из 20+
   тестовых вопросов по проектной деятельности.
3. Кодовая база проекта и подготовленная база знаний задокументированы.
