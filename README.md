# ИИ-ассистент по проектной деятельности

## Описание

ИИ-ассистент для студентов на основе RAG-архитектуры (Retrieval-Augmented Generation). Помогает студентам при выполнении проектной деятельности, консультируя по вопросам управления проектами, Agile, Scrum, DevOps и других инженерных практик.

В отличие от обычных LLM-чатов, ассистент даёт ответы строго на основе проверенной базы знаний (статьи, книги, ГОСТы, методические материалы), что обеспечивает релевантность и достоверность информации.

## Функциональность

- Консультации по проектной деятельности на основе загруженной базы знаний
- RAG-пайплайн: поиск по векторной базе + генерация ответа через LLM
- Веб-интерфейс для взаимодействия с ассистентом
- Аутентификация пользователей
- История диалогов

## Технологический стек

- **Backend:** Python 3.14, FastAPI
- **База данных:** PostgreSQL (SQLAlchemy async)
- **Векторное хранилище:** Qdrant
- **LLM:** OpenAI (через LangChain)
- **Сбор документации:** markitdown (PDF, DOCX)
- **Контейнеризация:** Docker + Docker Compose

## Быстрый старт

### Требования

- Docker и Docker Compose
- API-ключ OpenAI

### Запуск

1. Скопируйте конфиг:
   ```bash
   cp .env.example .env
   ```

2. Отредактируйте `.env` и укажите ваши ключи:
   ```bash
   OPENAI_API_KEY=your_key_here
   QDRANT_API_KEY=your_key_here  # опционально для облачного Qdrant
   ```

3. Запустите проект:
   ```bash
   docker-compose up -d
   ```

4. Откройте браузер и перейдите по адресу:
   ```
   http://localhost:8000
   ```

## Установка локально (без Docker)

```bash
# Установка зависимостей через uv
uv sync

# Настройка окружения
cp .env.example .env
# Отредактируйте .env

# Запуск приложения
uvicorn app.main:app --reload
```
